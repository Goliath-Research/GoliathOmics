# DomainPrograms

GoliathOmics workflow graphs (DomainPrograms) are compiled into `wf` nodes by the GoliathApp gateway.

**Today:** fixtures and profiles live under [`workflow_engine/domain/fixtures/`](../workflow_engine/domain/fixtures/) and [`workflow_engine/domain/profiles/`](../workflow_engine/domain/profiles/). R4 may copy or move selected programs here to match the Crop/Factory `domain_programs/` layout.
