# methyl_deconv

Python-native Houseman constrained projection for buffy-coat WGBS using the
published **FlowSorted.Blood.EPIC** IDOL marker library (Salas et al. 2018).

CLI: `methyl-cell-deconv --project <project.json> [--resolved-config …]`

Default seed basis: `methyl_deconv/data/flowsorted_blood_epic_idol_v1.json`.
