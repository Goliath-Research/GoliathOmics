# Integration Demos

This directory contains complete integration examples showing how to use MethylUtils in real-world scenarios.

## Files

### `integrated_architecture.py`
A comprehensive example showing how to integrate all MethylUtils components:

- Unified API usage across all modules
- Genome-scale processing workflows
- Performance monitoring and optimization
- GPU/CPU backend switching
- Memory management strategies

## Usage

```bash
python integrated_architecture.py
```

This example demonstrates:
- Loading and processing methylation samples
- Using the PositionAligner for genomic alignment
- Computing distance matrices with various metrics
- Performance profiling and monitoring
- Memory-efficient genome processing
