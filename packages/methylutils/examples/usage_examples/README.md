# Usage Examples

This directory contains basic usage examples to help you get started with MethylUtils.

## Files

### `example_methyl_sample_usage.py`
Basic usage examples for the MethylSample class:

- Creating and loading methylation samples
- Basic data manipulation
- Position alignment examples
- Simple distance computations

## Usage

```bash
python example_methyl_sample_usage.py
```

This example provides a gentle introduction to:
- MethylSample data structures
- Basic genomic operations
- Position alignment workflows
- Distance metric calculations
