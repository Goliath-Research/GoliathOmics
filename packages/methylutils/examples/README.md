# MethylUtils Examples

This directory contains examples and demonstrations for using MethylUtils.

## Directory Structure

### `integration_demos/`
Complete integration examples showing how to use MethylUtils for real-world scenarios:
- `integrated_architecture.py` - Unified architecture example integrating all MethylUtils components

### `package_demos/`
Demonstrations of specific package features and capabilities:
- `container_optimization.py` - Container optimization strategies for NVIDIA GH200
- `parallel_io.py` - Parallel I/O implementation examples

### `usage_examples/`
Basic usage examples showing how to get started with MethylUtils:
- `example_methyl_sample_usage.py` - Basic usage examples for MethylSample

## Running Examples

Each example can be run independently. Make sure you have the required dependencies installed:

```bash
pip install -r requirements.txt
```

Then run any example:

```bash
python examples/integration_demos/integrated_architecture.py
```
