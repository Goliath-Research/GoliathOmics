# Package Demos

This directory contains demonstrations of specific MethylUtils package features and advanced capabilities.

## Files

### `container_optimization.py`
Demonstrates container optimization strategies for NVIDIA GH200:

- Memory pooling for 96GB GPU memory
- Multi-threaded CPU processing optimization
- Container-specific performance tuning
- Resource management strategies

### `parallel_io.py`
Examples of parallel I/O implementations:

- Parallel HDF5 reading with threading
- Memory-mapped I/O for large files
- Asynchronous data loading
- I/O performance optimization techniques

## Usage

```bash
python container_optimization.py
python parallel_io.py
```

These examples show advanced usage patterns and optimization techniques for specific scenarios.
