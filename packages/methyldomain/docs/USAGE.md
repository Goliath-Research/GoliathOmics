# methyldomain — usage

Infrastructure package — not a standalone operator CLI. Consumed by workflow engine, workers, and gateway for typed scope variables and CAAS.

## Developer commands

```bash
source .venv/bin/activate
methyl-export-domain-schemas
methyl-export-domain-schemas --check
```
